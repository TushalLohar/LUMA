# 🚀 LUMA ARCADE

> **High-Octane 120 FPS Web Space Shooter**  
> Play free in your browser with zero downloads, responsive touch/keyboard controls, dynamic power-ups, epic boss battles, and iconic superhero suit themes.

---

## ⚡ Features

- **⚡ 120 FPS Deterministic Physics & Render Engine**: Powered by HTML5 2D Canvas with off-screen radial glow caching and zero-reflow coordinate handling.
- **🦸 Dynamic Hero Suit Themes**:
  - **🕸️ Spider-Man**: Web-Slinger Suit with neon cyan & crimson energy arcs.
  - **🤖 Iron Man**: Mark 85 Arc Reactor setup with repulsor beam aesthetics.
  - **🌩️ Storm Lord (Thor)**: Thunder god divine sky weapon with ambient storm flashes & electric rain particles.
- **💥 Arsenal & Power-ups**:
  - **Spread Shot** (Multi-wave spread lasers)
  - **Rapid Fire** (High-voltage continuous stream)
  - **Shield** (Energy deflector field)
  - **Homing Missiles** (Target-tracking warheads)
  - **Nova Bomb** (Full-screen enemy wipe)
- **👾 Escalating Alien Waves & Boss Battles**: Endless wave progression with increasing enemy speed, fire rate, and phase-shifting boss encounters.
- **🎵 Zero-Dependency Web Audio Synthesizer**: Pure Web Audio API procedural sound effects and retro synthwave background loop.
- **📱 Fully Responsive**: Touch drag support for mobile/tablets & WASD/Arrow keys for desktop.

---

## 🎮 Controls

| Action | Keyboard | Touch / Mobile |
|---|---|---|
| **Move** | `WASD` / `Arrow Keys` | Drag on Screen |
| **Fire** | `Spacebar` | Auto-fire / Touch |
| **Pause** | `ESC` | Pause Icon (Top Right) |
| **Mute Sound** | `M` | Speaker Icon (Top Right) |
| **Restart Game** | `Enter` | Tap Screen |

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/router) & [React 19](https://react.dev/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Graphics**: HTML5 2D Canvas Context (Custom Game & Render Engine)
- **Audio**: Web Audio API (Synthesized SFX + Music)
- **Deployment**: Cloudflare Workers / Vercel / Netlify

## 💻 Local Development

### Prerequisites

Ensure you have **Node.js** (v18+) and **npm** installed.

### Setup & Run

```bash
# 1. Clone the repository
git clone https://github.com/TushalLohar/LUMA.git

# 2. Navigate to project folder
cd "Game Feedback Hub"

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to play!

### Production Build

```bash
npm run build
```
